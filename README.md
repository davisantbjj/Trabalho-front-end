# Trabalho Front-End - UNIT

Este é um projeto de front-end desenvolvido como parte das atividades acadêmicas na **UNIT (Universidade Tiradentes)**. O objetivo do projeto foi criar uma estrutura de páginas web integradas, utilizando tecnologias fundamentais de desenvolvimento web.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

* **HTML5**: Estruturação de todas as páginas do site.
* **CSS3**: Estilização visual, layouts e design responsivo.

## 📂 Estrutura do Projeto

O repositório está organizado da seguinte forma:

* `index.html`: Página principal/inicial do projeto.
* `home-pag.html`: Página de conteúdo principal.
* `port-davi.html`: Página de portfólio/perfil individual.
* `kailne.html` e `luiz.html`: Páginas dedicadas aos demais integrantes do grupo.
* `/style`: Contém os arquivos de folha de estilo (CSS).
* `/img`: Armazena as imagens e recursos visuais utilizados no site.
* `/arquivos`: Outros documentos e arquivos complementares.
